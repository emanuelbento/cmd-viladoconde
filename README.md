# CMD Vila do Conde

Código de interação do site do Centro Médico e Dentário de Vila do Conde (Webflow).

- `src/` código fonte
- `dist/cmd.min.js` carregado em todas as páginas
- `dist/gl.min.js` hero em WebGL da homepage
- `audio/clicks.mp3` sons da interface

Servido por jsDelivr a partir de uma tag:

```html
<script src="https://cdn.jsdelivr.net/gh/emanuelbento/cmd-viladoconde@v1.0.0/dist/cmd.min.js"></script>
```

`./build.sh` gera a pasta `dist`.
